Sistema de Veículos em POO (Python)

Pequeno script que demonstra os conceitos fundamentais de Programação Orientada a Objetos: definição de classe, atributos e instanciação de objetos.

Conceitos aplicados
Atributo de classe (color): compartilhado por todas as instâncias.
Construtor (__init__): define os atributos próprios de cada objeto (max_speed, mileage) na criação.
Método de instância (assign_seating_capacity): altera um atributo do objeto após sua criação.
Múltiplas instâncias independentes: carro1 e carro2 são objetos separados da mesma classe, cada um com seus próprios valores.
